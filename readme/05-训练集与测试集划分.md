# 05 - 训练集与测试集划分

## 结论：**没有训练集 / 测试集划分**

`depression.R` **全程未做** 传统的训练集–测试集（或训练–验证–测试）拆分。虽然加载了 `caret`（常用于数据划分），但脚本里 **从未调用** `createDataPartition` 或类似函数。

---

## 脚本里实际用到的数据对象

```
Rdata（原始全量数据）
    │
    ├─→ polr 模型（含 NA 行）
    │
    └─→ na.omit(Rdata)
            │
            ├─→ Rdata_clean
            └─→ clean_data（与 Rdata_clean 实质相同）
                    │
                    ├─→ rms_model 建模与验证
                    └─→ Bootstrap 重抽样 → sampled_data
```

| 对象 | 来源 | 与 Rdata 的关系 | 用途 |
|------|------|-----------------|------|
| **`Rdata`** | 需事先外部加载 | 原始完整数据 | 预处理、`polr` 建模 |
| **`Rdata_clean`** | `na.omit(Rdata)` | Rdata 去掉含 NA 的行 | `model1`、`boot()` |
| **`clean_data`** | `na.omit(Rdata)` | 与 `Rdata_clean` **实质相同** | `rms_model`、ROC/AUC、列线图、validate/calibrate |
| **`sampled_data`** | 对 `Rdata_clean` 有放回抽样 | Bootstrap 的一次子样本，**不是**测试集 | 仅用于调试维度 |

**没有任何对象被定义为「训练集」或「测试集」。**

---

## 建模与验证各自用哪份数据

### 1. `polr` 模型

```r
model <- polr(Rdata$抑郁等级 ~ SSRS + ..., data = Rdata, Hess = TRUE)
```

- 使用 **`Rdata` 全量**（含缺失行）
- **无** 训练/测试划分

### 2. `rms_model` 主模型

```r
clean_data <- na.omit(Rdata)
rms_model <- lrm(抑郁等级 ~ SSRS + PSQI + ..., data = clean_data)
```

- 使用 **`clean_data`**（= 完整案例子集）
- 拟合、预测、验证 **都在同一份 `clean_data` 上**

### 3. 后续「验证」

| 步骤 | 数据 |
|------|------|
| `validate()` / `calibrate()` | 仍是拟合 `rms_model` 的 **`clean_data`**（Bootstrap 内部验证） |
| ROC / AUC | 用 `clean_data` 的拟合值与真实标签对比（**样本内**） |
| `boot()` | 从 **`Rdata_clean`** 有放回重抽样，在 Bootstrap 样本上重拟合 |

---

## 容易误解的两处代码

### 1. `sample()` 不是划分测试集

```r
sample_indices <- sample(1:nrow(Rdata_clean), replace = TRUE)
sampled_data <- Rdata_clean[sample_indices, ]
```

- `replace = TRUE` 表示 **有放回 Bootstrap 抽样**
- 目的是重抽样做稳定性分析，**不是** 划出 hold-out 测试集

### 2. `brant_test` 不是测试集

```r
brant_test <- brant(model)
```

- 这是 **Brant 比例优势检验** 的结果对象
- 与「测试集」无关

---

## 和 Rdata 的关系（一句话）

> **`Rdata` 是唯一原始数据源；`Rdata_clean` / `clean_data` 只是去掉缺失值后的子集；Bootstrap 的 `sampled_data` 是从完整案例中有放回抽出的重复样本。全程没有从 Rdata 中拆出独立的测试集。**

用数据流表示：

```
Rdata（4054 行，原始）
    │
    ├─→ polr：用全量 Rdata（含 NA）
    │
    └─→ na.omit()
            │
            └─→ Rdata_clean / clean_data（约 1283 行完整案例）
                    │
                    ├─→ 拟合 rms_model
                    ├─→ 在同一数据上 predict、ROC、calibrate、validate
                    └─→ Bootstrap 有放回重抽样（仍来自这 1283 行）
```

---

## 实际影响

| 方面 | 现状 |
|------|------|
| 是否存在训练/测试划分 | **否** |
| 验证方式 | 同数据 **内部验证**（Bootstrap 校正 C-index、校准曲线、样本内 AUC） |
| 能否评估「泛化到新样本」的表现 | **不能**，除非另做 hold-out 或外部验证 |
| 与 Rdata 关系 | 所有分析数据 **均来自 Rdata**，只是 NA 剔除和 Bootstrap 重抽样 |

## 若需补充训练/测试评估

可在脚本中显式增加划分，例如从 `clean_data` 中拆出 70% 训练、30% 测试，且 **测试集不参与拟合**。示例：

```r
library(caret)
set.seed(123)
idx <- createDataPartition(clean_data$抑郁等级, p = 0.7, list = FALSE)
train_data <- clean_data[idx, ]
test_data  <- clean_data[-idx, ]
```

然后在 `train_data` 上拟合，在 `test_data` 上评估混淆矩阵、Accuracy 等指标。
