# 01 - depression.R 脚本功能与输入输出

## 总体功能

`depression.R` 是一个 **产后抑郁（EPDS）有序多分类预测与模型评估** 的 R 分析脚本。

核心流程：

1. 数据预处理（因子编码）
2. 有序逻辑回归建模
3. 比例优势假设检验
4. 列线图（Nomogram）可视化
5. Bootstrap 内部验证与校准
6. ROC / AUC 判别能力评估

研究场景：基于社会支持、睡眠、激素、孕期抑郁、人口学/行为等变量，预测产后抑郁等级（正常 → 轻度 → 中度 → 重度）。

### 2. 依赖 R 包

| 包 | 用途 |

| `pROC` | ROC / AUC |

| `Hmisc`, `dplyr`, `caret`, `ggplot2` | 辅助（部分未实际使用） |

脚本开头会尝试 `install.packages()`，适合首次运行环境。

### 3. 数据框 `Rdata` 中的关键变量

**因变量（结局）：**

- `EPDS级别` → 重编码为有序因子 `抑郁等级`：1–4 对应「正常 / 轻度 / 中度 / 重度」

**自变量（预测因子）：**

| 变量 | 类型 | 说明 |
|---|---|---|
| `SSRS` | 连续 | 社会支持量表 |
| `PSQI` | 连续 | 匹兹堡睡眠质量指数 |
| `分娩次数` | 数值 | 分娩次数 |
| `TPOab` | 连续 | 甲状腺过氧化物酶抗体 |
| `孕酮` | 连续 | 孕酮水平 |
| `孕期EPDS` | 连续 | 孕期 EPDS 得分 |
| `丈夫学历` | 分类 1–3 | 大专本科 / 研究生 / 其他 |
| `本人职业` | 分类 1–5 | 体制工作 / 技术员 / 职员 / 个体户 / 其他 |
| `吸烟` | 二分类 | 是 / 否 |
| `倾诉方式` | 分类 1–4 | 无 / 被动 / 1-2人 / 主动 |
| `求助方式` | 分类 1–4 | 无 / 很少 / 有时 / 经常 |
| `母乳` | 分类 1–3 | 否 / 混合 / 是 |

## 输出

脚本以 **控制台打印 + 图形窗口** 为主，未写文件导出。

### 控制台输出

| 输出内容 | 来源 |
|---|---|
| 各变量 `summary()` | 预处理阶段 |
| `polr` 回归系数与标准误 | `summary(model)` |
| 带 p 值的系数表 | 手动计算 `pnorm()` |
| Brant 比例优势检验 | `brant(model)` |
| `lrm` 模型摘要 | `print(rms_model)` |
| Bootstrap 验证（Dxy、校正 C-index） | `validate(rms_model)` |
| 多阈值 AUC 及 95% CI | 循环 ROC 分析 |
| Bootstrap AUC 及 BCa 置信区间 | `boot()` + `boot.ci()` |

### 图形输出

| 图形 | 函数 |
|---|---|
| 列线图（Nomogram） | `nomogram()` + `plot()`，标签「产后抑郁风险」 |
| 校准曲线 | `calibrate()` + `plot()` |
| ROC 曲线 | `plot(simple_roc)` |

### 中间对象（内存中）

- `model`：`polr` 有序逻辑回归
- `model1` / `rms_model`：`rms::lrm` 模型
- `pred_probs`：拟合概率
- `validate_boot`、`calibration`、`roc_obj`、`auc_results`、`boot_results` 等

```
数据预处理
    ↓

    ↓

    ↓

    ↓

```
