# 02 - Rdata 数据要求

运行 `depression.R` 前，R 环境中必须事先存在一个名为 **`Rdata`** 的数据框。脚本本身 **没有** 数据加载语句。

---

## 加载方式

对象名必须是 **`Rdata`**（大小写一致），例如：

```r
# 方式 A：从 RData 文件加载
load("你的数据路径.RData")

# 方式 B：从 CSV 读入
Rdata <- read.csv("你的数据路径.csv", fileEncoding = "UTF-8")

# 方式 C：从 Excel 读入（推荐，见 03-Rdata.xlsx数据分析.md）
library(readxl)
Rdata <- read_excel("Rdata.xlsx", sheet = "产后总表")
```

加载后建议检查：

```r
str(Rdata)
names(Rdata)
nrow(Rdata)
```

---

## 必须包含的列（共 13 个）

缺任意一列都会在运行时报错。

### 因变量（1 列）

| 列名 | 脚本中的用途 | 原始取值要求 | 编码含义 |
|------|-------------|-------------|---------|
| `EPDS级别` | 被转换为 `抑郁等级`（有序因子） | 数值 **1, 2, 3, 4** | 1=正常，2=轻度，3=中度，4=重度 |

> 脚本会生成新列 `抑郁等级`，但 **`EPDS级别` 必须在原始 `Rdata` 中就存在**。

### 自变量（12 列）

#### 连续/数值型（6 列）

| 列名 | 类型要求 | 说明 |
|------|---------|------|
| `SSRS` | 数值 | 社会支持量表得分 |
| `PSQI` | 数值 | 匹兹堡睡眠质量指数 |
| `分娩次数` | 数值 | 分娩次数 |
| `TPOab` | 数值 | 甲状腺过氧化物酶抗体 |
| `孕酮` | 数值 | 孕酮水平 |
| `孕期EPDS` | 数值 | 孕期 EPDS 得分 |

#### 分类型（6 列，需为数值编码）

| 列名 | 允许取值 | 编码含义 |
|------|---------|---------|
| `丈夫学历` | 1, 2, 3 | 1=大专/本科，2=研究生，3=其他 |
| `本人职业` | 1, 2, 3, 4, 5 | 1=体制工作，2=技术员，3=职员，4=个体户，5=其他 |
| `吸烟` | 1, 2 | 1=是，2=否 |
| `倾诉方式` | 1, 2, 3, 4 | 1=无，2=被动，3=1-2人，4=主动 |
| `求助方式` | 1, 2, 3, 4 | 1=无，2=很少，3=有时，4=经常 |
| `母乳` | 1, 2, 3 | 1=否，2=混合，3=是 |

## 数据格式要求

### 对象结构

- **类型**：`data.frame`
- **对象名**：必须是 `Rdata`
- **每行**：代表一个研究对象（如一名产后妇女）
- **列名**：必须与上表 **完全一致**（中文列名）

### 编码方式

脚本假设分类变量是 **数字编码**，再在脚本内转为带中文标签的 `factor`：

```r
Rdata$丈夫学历 <- factor(Rdata$丈夫学历,
                         levels = c(1, 2, 3),
                         labels = c("大专、本科", "研究生", "其他"))
```

因此：

- 分类变量应存为 **1, 2, 3…** 这类数值
- **不要** 事先存成中文标签（如 `"是"` / `"否"`），否则 `factor()` 可能产生大量 `NA`
- 连续变量应为 **数值型**

### 缺失值

脚本多处使用 `na.omit(Rdata)`：**13 列中任意一列有 `NA`，该行会被整行删除**。

建议在加载后自查：

```r
vars_needed <- c(
  "EPDS级别", "SSRS", "PSQI", "分娩次数", "TPOab", "孕酮", "孕期EPDS",
  "丈夫学历", "本人职业", "吸烟", "倾诉方式", "求助方式", "母乳"
)
sum(complete.cases(Rdata[, vars_needed]))  # 可用样本数
colSums(is.na(Rdata[, vars_needed]))       # 各列缺失数
```

### 样本量

模型包含 **12 个预测变量 + 有序 4 类结局**，建议完整案例 **至少 100–150 行以上**（更稳妥 200+），且四个 EPDS 等级都最好有一定频数。

## 加载前检查清单

```r
required_cols <- c(
  "EPDS级别", "SSRS", "PSQI", "分娩次数", "TPOab", "孕酮", "孕期EPDS",
  "丈夫学历", "本人职业", "吸烟", "倾诉方式", "求助方式", "母乳"
)

exists("Rdata")                              # 1. 对象是否存在
setdiff(required_cols, names(Rdata))         # 2. 列是否齐全
sum(complete.cases(Rdata[, required_cols]))  # 3. 完整案例数
```
