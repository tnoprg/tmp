## 相关文件

- 分析脚本：`../depression.R`
- 数据文件：`../Rdata.xlsx`（主工作表：`产后总表`）

## 快速结论

- 脚本用于 **产后抑郁等级（EPDS）有序多分类预测**。
- 运行前需事先加载名为 **`Rdata`** 的数据框；`Rdata.xlsx` 的 **`产后总表`** 可完全提供所需 13 个变量。
- 完整案例约 **1283 行**（原始 4054 行，`na.omit` 后）。
- 脚本 **没有** 训练集/测试集划分；验证主要为 Bootstrap 内部验证、校准曲线、C-index、ROC/AUC。
- 脚本存在部分代码错误，尚不能完整跑通（见各文档说明）。
