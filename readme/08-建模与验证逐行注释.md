### 2.3 样本内 ROC / AUC（164–211）

用 ROC 曲线和 AUC 评估判别能力；将有序结局 **二值化** 后计算。

#### 2.3.1 基础 ROC（164–174）

| 行号 | 源码 | 注释 |
|------|------|------|
| 164 | `pred_probs <- predict(rms_model, type = "fitted")` | 获取每个样本的 **拟合概率**（in-sample，同一数据上拟合又预测） |
| 166 | `depression_levels <- sort(unique(clean_data$抑郁等级))` | 提取并排序抑郁等级 levels：正常、轻度、中度、重度 |
| 168 | `binary_outcome <- as.numeric(clean_data$抑郁等级 > min(depression_levels))` | 二值化：**是否高于最低等级**（即是否非「正常」） |

| 170 | `roc_obj <- roc(binary_outcome, pred_probs)` | 用 `pROC` 计算 ROC 曲线对象 |

| 行号 | 源码 | 注释 |
|------|------|------|
| 176 | `roc_list <- list()` | 初始化空列表，存放各阈值的 ROC 对象 |

### 2.5 Bootstrap AUC 第一版（221–253）

通过 Bootstrap 估计 AUC 的稳定性；**本段含多处错误**。

| 行号 | 源码 | 注释 |
|------|------|------|
| 221 | `boot_auc <- function(data, indices) {` | 定义 Bootstrap 统计量函数 |
| 223 | `sampled_data <- data[indices, ]` | 按 `boot()` 传入的索引取 Bootstrap 样本 |
| 226–228 | `boot_model <- lrm(..., data = sampled_data, x = TRUE, y = TRUE)` | 在 Bootstrap 样本上 **重新拟合** lrm 模型 |
| 231 | `pred_prob <- predict(boot_model, newdata = Rdata_clean, type = "fitted")` | 用 Bootstrap 模型在 **全量 Rdata_clean** 上预测 |
| | | ⚠️ 拟合集与预测集不一致，逻辑上有争议 |
| 234 | `roc_obj <- roc(Rdata_clean$抑郁等级, pred_prob)` | 用 4 类有序因子直接做 ROC，语义不明确 |
| 235 | `return(as.numeric(roc_obj$auc))` | 返回 AUC 标量 |
| 236 | `}` | 函数结束 |
| 238 | `set.seed(123)` | 固定随机种子 |
| 239 | `boot_results <- boot(data = Rdata_clean, statistic = boot_auc, R = 1000)` | 执行 1000 次 Bootstrap，结果存入 `boot_results` |
| 242–245 | `roc_obj <- roc(...); return(...); }` | ⚠️ **孤立代码片段**，无函数头，**语法错误** |
| 247–248 | `set.seed(123); boot_results <- boot(data = sample_data, ...)` | ⚠️ `sample_data` **未定义**，会报错 |

**设计意图：**

- 通过重复抽样评估 AUC 是否稳定
- 输出 `mean_auc` 和 BCa 置信区间

**实际问题：**

- 241–245 行残缺，241 行之后无法正常解析
- 248 行引用不存在的 `sample_data`
- 即使修复，第一版 `boot_auc` 的预测逻辑也有方法学问题
