# 06 - Bootstrap 抽样说明

## Bootstrap 抽样是什么？

**Bootstrap（自助法）** 是一种统计重抽样方法：从 **已有样本** 里 **有放回地随机抽取**，反复生成很多份「新样本」，用来估计模型指标的不确定性和过拟合程度。

可以把它理解成：**不额外收集新数据，用现有数据反复"模拟抽样实验"。**

---

## 核心概念：有放回抽样

假设你有 5 个病人：`A, B, C, D, E`

做一次 Bootstrap 抽样（有放回）可能得到：

```
第1次：A, C, C, E, B   ← C 被抽到两次
第2次：D, D, A, B, E   ← D 被抽到两次
第3次：B, A, C, D, E   ← 恰好和原样本一样（也可能发生）
```

特点：

- 每次抽到的样本量和原数据 **一样大**（例如 1283 行 → 仍抽 1283 行）
- 同一个个体可以被抽到 **0 次、1 次或多次**
- 大约 **63%** 的原始样本会出现在某一次 Bootstrap 样本中，约 **37%** 不会出现

---

## 为什么要这样做？

真实研究里，往往只有 **一份数据**，没有独立测试集。Bootstrap 用来回答：

> 「如果这个模型换一批相似病人，结果会不会差很多？指标是不是被高估了？」

常见用途：

| 用途 | 在 depression.R 中的体现 |
|------|--------------------------|
| 估计置信区间 | AUC 的 95% CI |
| 校正过拟合（乐观偏差） | `validate(rms_model, method = "boot")` |
| 评估模型稳定性 | 重复拟合 1000 次，看指标分布 |

---

## 在 depression.R 里的具体用法

### 1. 模型内部验证

```r
validate_boot <- validate(rms_model, method = "boot", B = 1000)
```

含义：

1. 从 `clean_data`（约 1283 行）有放回抽 1283 行
2. 在这份 Bootstrap 样本上 **重新拟合** 模型
3. 计算 C-index 等指标
4. 重复 **1000 次**（`B = 1000`）
5. 对比「样本内表现」和「Bootstrap 表现」，得到 **校正后的 C-index**

目的：减轻 **过拟合乐观偏差**（模型在自己数据上看起来很好，泛化可能没那么好）。

---

### 2. 校准曲线

```r
calibrate(rms_model, method = "boot", B = 1000)
```

同样通过 Bootstrap 重抽样，看预测概率是否稳定、是否校准良好。

---

### 3. AUC 的 Bootstrap 置信区间

```r
ci <- ci.auc(roc_obj, method = "bootstrap", boot.n = 1000)
```

重复抽样计算很多次 AUC，得到 AUC 的 **95% 置信区间**，表示「AUC 可能落在哪个范围」。

---

### 4. 脚本末尾的 `sample()`

```r
sample_indices <- sample(1:nrow(Rdata_clean), replace = TRUE)
sampled_data <- Rdata_clean[sample_indices, ]
```

这就是 **一次** Bootstrap 抽样示例：`replace = TRUE` 表示有放回。

---

## 和「训练集 / 测试集划分」的区别

| | Bootstrap | 训练/测试划分 |
|---|-----------|---------------|
| 是否划分数据 | 一般不固定划出测试集 | 明确分成训练集和测试集 |
| 抽样方式 | 有放回，可重复 | 无放回，每人只进一个集合 |
| 目的 | 估计不确定性、校正过拟合 | 评估泛化到新样本的表现 |
| 是否用新数据 | 否，仍来自同一份 Rdata | 测试集不参与训练 |

脚本用的是 Bootstrap **内部验证**，不是 hold-out 测试集。

---

## 直观类比

把 1283 个病人看作 1283 张扑克牌：

- **Bootstrap**：洗好后 **抽 1283 次（可重复）**，每次得到一副新牌堆，重复 1000 次看结果是否稳定
- **训练/测试划分**：把牌 **分成两堆**，一堆用来学，一堆用来考，互不重叠

---

## 一次 Bootstrap 循环发生了什么

以 `validate(rms_model, method = "boot", B = 1000)` 为例：

```
原始数据 clean_data（1283 行）
        │
        ▼
  有放回抽取 1283 行 → Bootstrap 样本 #1
        │
        ▼
  在 Bootstrap 样本上重新拟合 lrm 模型
        │
        ▼
  计算 C-index 等指标 → 记录结果 #1
        │
        ▼
  重复 1000 次 → 得到 1000 个指标值
        │
        ▼
  对比样本内指标 vs Bootstrap 均值 → 校正过拟合偏差
```

---

## 一句话总结

> **Bootstrap 抽样 = 从现有数据中有放回地反复抽取同样大小的样本，多次重算模型指标，用来估计结果有多可靠、有没有过拟合。**

在 `depression.R` 里，Bootstrap 用来校正 C-index、画校准曲线、算 AUC 置信区间；**它不能替代** 独立测试集或外部验证，但能在一套数据上给出比单纯「样本内指标」更稳健的内部评估。
