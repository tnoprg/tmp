## 如何加载为 Rdata

在运行 `depression.R` 之前，先执行：

```r
library(readxl)

Rdata <- read_excel("Rdata.xlsx", sheet = "产后总表")

# 可选：只保留建模相关列
Rdata <- Rdata[, c(
  "EPDS级别", "SSRS", "PSQI", "分娩次数", "TPOab", "孕酮", "孕期EPDS",
  "丈夫学历", "本人职业", "吸烟", "倾诉方式", "求助方式", "母乳"
)]

# 检查完整案例数（脚本 na.omit 后大约剩这么多）
sum(complete.cases(Rdata))
# 预期结果：1283
```

---

## 需要注意的点

1. **必须指定工作表 `产后总表`**，不要默认读错 sheet。
2. **`na.omit` 后样本从 4054 降到 1283**，主要因 `孕酮`、`PSQI` 缺失。
3. **`分娩次数` 含 0**（初产），脚本 `as.numeric()` 可正常处理。
4. **脚本自身仍有代码错误**，与数据无关，但会阻止完整跑通。
